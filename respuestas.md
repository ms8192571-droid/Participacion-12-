# Respuestas — Plugin Detective

## 1. Skill frente a plugin
Un Skill contiene instrucciones y recursos reutilizables que ayudan al agente a realizar una tarea especializada. Un plugin puede empaquetar diferentes componentes, como comandos, hooks, MCP y otras extensiones, para distribuir funcionalidades adicionales.

## 2. Ralph Loop
Ralph Loop podría repetir el análisis hasta un máximo de 3 iteraciones, comprobando cada vez que las alertas tengan evidencia, que las filas sean correctas y que los tokens estén ocultos. El proceso se detendría cuando todas las comprobaciones fueran correctas o al alcanzar las 3 iteraciones. No se deben inventar evidencias nuevas.
